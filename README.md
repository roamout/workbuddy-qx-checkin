# WorkBuddy · Quantumult X 多账号自动签到

> 纯手机使用，支持**多个 WorkBuddy 账号**：一个脚本同时完成「多账号登录令牌自动捕获」「每日自动签到」「派 Buddy 旅行」「真实积分余额显示」，结果合并成一条通知。

- 每个账号独立刷新令牌、签到、查余额，互不影响；
- 依次切换登录即可自动累积账号，无需手动粘贴令牌；
- 账号按「昵称（手机尾号）」显示，如 `Roam（6351）`，昵称重复也能区分；
- 仓库默认不含任何个人令牌，可直接分享。

---

## ✨ 功能

- **多账号自动捕获**：登录账号 A 自动存 A，切到账号 B 再存 B……按账号唯一 ID 去重，重复登录不会覆盖、不会重复通知。
- **每日自动签到**：普通日 +100，第 7 天 +1000（积分取自接口真实返回，不写死）。
- **派 Buddy 旅行**：自动领取到达奖励、再次派出。
- **真实余额**：奖励到账后查询账户资源汇总接口，播报真实可用积分。
- **合并通知**：所有账号结果合并成一条通知，逐账号展示，只响一次。
- **令牌自动续期**：每个账号每次运行自动换令牌并回写。
- **自动兼容单账号**：只有一个账号时，行为与单账号版一致。

---

## 🧩 一个脚本，两种模式

| 触发方式 | 模式 | 作用 |
| --- | --- | --- |
| `[rewrite_local]` | 捕获模式 | 登录时把当前账号的令牌存入本机（多账号按 ID 去重累积） |
| `[task_local]` | 签到模式 | 串行签到所有账号，合并成一条通知 |

## 📦 安装

1. 把 `workbuddy.js` 放入 QX 本地脚本目录：`文件 App → iCloud Drive → Quantumult X → Scripts`。
2. **安装并完全信任 QX 证书**：
   - QX「设置 → MitM」生成并下载 CA 证书；
   - 系统「设置 → 通用 → VPN与设备管理」安装描述文件；
   - 系统「设置 → 通用 → 关于本机 → 证书信任设置」对 Quantumult X 证书**打开完全信任**；
   - 回到 QX 确认 **MitM 已开启**。
3. 加入下面的配置并生效。

## ⚙️ QX 配置

```ini
[rewrite_local]
^https?://(copilot\.tencent\.com|www\.codebuddy\.cn|www\.workbuddy\.cn)/.* url script-response-body workbuddy.js

[task_local]
0 9 * * * workbuddy.js, tag=WorkBuddy多账号签到, enabled=true

[mitm]
hostname = copilot.tencent.com, www.codebuddy.cn, www.workbuddy.cn
```

## 🔑 添加多个账号

1. 用 Safari 打开 `https://www.codebuddy.cn/login`，登录**账号 A**，收到「🔑 已捕获账号 Roam（6351）」；
2. **退出登录**，再登录**账号 B、C……**，每登录一个会自动累积一个；
3. 全部登录完即可。之后每天定时任务会签到全部账号。

> 推荐用 Safari 网页版（无证书绑定，最稳）。App 若做了证书绑定抓不到，退回网页版即可。

## ❓ 常见问题

**账号很多会不会很慢？** 账号串行处理，每个账号约 1～2 秒，后台任务可接受。

**怎么删除某个账号？** 在 QX 本地存储里删除 `workbuddy_accounts_v2` 即清空全部；如需只删单个，可先备份该键再手动编辑其 JSON（数组里删掉对应项）。

**之前用过单账号版怎么办？** 脚本会自动读取旧键 `workbuddy_checkin_rt` 并迁移为一个账号，之后直接按多账号流程登录即可。

**令牌会过期吗？** 约 60 天，任务每次运行会自动换令牌；某账号长期未运行导致失效，重新登录该账号即可。

**积分数字真实吗？** 刚签到显示签到接口返回的实际到账 `credit`，已签显示状态接口的 `daily_credit`（第 7 天为 1000）；接口没给数字时不显示，绝不编造。

## 🔒 安全与隐私

- 所有账号令牌仅保存在**你本人设备**的 QX 本地存储，不发送到任何第三方服务器。
- 重写脚本只读取登录响应并原样放行，不修改服务器响应。
- 仓库默认不含任何个人令牌，请勿把含真实令牌的文件上传公开仓库。
- 仅用于你本人拥有/授权的账号，请勿搭建集中收集他人令牌的服务。
